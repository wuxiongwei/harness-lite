### Stock_make_money 现象："运行运行就停了，经常出现"
- 发现日期：2026-06-16
- 来源：用户在 stock_make_money 实战 H-L v1.0.4-v1.0.12 期间观察
- 现象：
  - claude REPL 跑着跑着停止响应或退出
  - 频次：经常出现
  - 用户原话："运行运行就停了，经常出现，不知道是什么原因"
  - **2026-06-16 追加细节**：用户报告卡住时屏幕最后一个符号是 **冒号"："**
- **诊断（高置信度）**：不是 H-L 的 bug，是 Claude Code 响应流被中断
  - 冒号位置说明 AI 正在生成文字（"以下：" / "原因：" / "步骤："），流被打断
  - hook / skill / subagent 卡住的话断点不会是文字中段冒号
  - 真根因（按概率）：①API 响应流截断 ②网络瞬断 ③stop_reason 异常但客户端未提示
- **应对手段**（已告诉用户）：
  - 卡冒号 → 敲 `继续` 回车（多数能恢复）
  - 完全卡死 → Ctrl+C 两次 + 重启 `claude`（历史保留）
- 影响范围：**不在 H-L 责任面**，记录此条仅为帮用户分辨"H-L 问题 vs Claude Code 问题"
- 处理状态：📌 不修（非 H-L 范围），保留观察
- 关联：v1.0.12 修了 hook if 字段格式（之前 stock 装的 v1.0.4-v1.0.11 含错格式 if，但这与"冒号截断"症状无关）
- 待用户进一步观察：(1) 卡住前会话是否已输出大量内容（>10k token）？(2) 卡住时网络是否同时不稳？

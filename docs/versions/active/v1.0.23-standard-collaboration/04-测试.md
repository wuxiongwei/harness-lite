## 3. 矩阵测试（T1-T8）

### T1 · 分支命名违反约定

**前提**：`.claude/branch-strategy.md` 存在 + 命名规范要求 `feat/<short-name>`

**操作**：用户当前分支名为 `alice-new-feature`（缺类型前缀）

**预期**：
1. AI 准备 `git commit` 前 Read branch-strategy.md
2. 解析当前分支名
3. 不匹配规范 → **软提醒**：
   ```
   ⚠️ 当前分支 `alice-new-feature` 不符合 .claude/branch-strategy.md 的命名规范。
      继续 commit / push？(yes/rename)
      rename → 提示 git branch -m feat/<新名>
   ```
4. 用户选 yes → 继续 commit
5. 用户选 rename → 提示重命名命令

**实施验证**：principles §14.4 触发点 + §14.3 软约束原则 ✅

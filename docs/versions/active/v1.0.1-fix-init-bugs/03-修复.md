## 修复改动清单

### Bug #1: sed 分隔符冲突（init.sh 渲染 CLAUDE.md）

**文件**：`scripts/init.sh`
**位置**：render_template_vars 函数

```diff
- sed -i.bak \
-     -e "s|{{TECH_STACK}}|$TECH_STACK_BACKEND \\\\| $TECH_STACK_FRONTEND \\\\| $DATABASE|g"
+ local tech_stack_str="$TECH_STACK_BACKEND / $TECH_STACK_FRONTEND / $DATABASE"
+ sed -i.bak \
+     -e "s#{{TECH_STACK}}#$tech_stack_str#g"
```

**关键变化**：分隔符 `|` → `#`，替换值的 `|` → `/`。

### Bug #2: uninstall.sh 残留 .claude/

**文件**：`scripts/uninstall.sh` 末尾


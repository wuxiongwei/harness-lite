# UC4 调研类验收用例

> 验证目标：调研动态适配用户主题，维度推荐合理
> v1.0.35 重构后验收重点

---

## UC4.1 技术选型调研（行为）

### 验收标准

"调研 XX 技术是否合适" → AI 推荐：性能/生态/学习曲线/替代方案等维度，不是固定模板。

### 验证步骤（手动）

1. 执行 `/harness-research`
2. 给一个技术选型问题
3. 观察 AI 推荐的维度是否合理

### 验证 prompt

```
/harness-research

调研一下 Flutter 做 mobile app 是否合适
```

### 通过条件

- AI 推荐维度包含：性能对比/生态成熟度/学习曲线/替代方案 等
- AI 不使用旧模板（person/company/tech）
- 推荐维度数量在 4-8 个
- AI 等待用户确认维度后才执行

---

## UC4.2 市场调研（行为）

### 验收标准

"调研 XX 市场" → AI 推荐：用户画像/竞品/市场规模/趋势等维度，可补充行业特有维度。

### 验证步骤（手动）

1. 执行 `/harness-research`
2. 给一个市场调研问题
3. 观察 AI 推荐的维度是否包含行业特有内容

### 验证 prompt

```
/harness-research

调研一下宠物食品市场
```

### 通过条件

- AI 推荐维度包含：用户画像/竞品格局/市场规模/增长趋势 等
- 可能补充行业特有维度（如供应链/法规合规）
- 不使用旧模板

---

## UC4.3 用户确认维度（行为）

### 验收标准

推荐维度后 AI 等待用户确认，不直接执行搜索。

### 验收步骤（手动）

1. 执行 `/harness-research`
2. 给任意调研主题
3. 观察 AI 是否停下来让用户确认

### 验证 prompt

```
/harness-research

调研一下这个 SaaS 项目的可行性
```

### 通过条件

- AI 输出推荐维度列表
- AI 输出确认选项：[1]确认 [2]增加 [3]删除 [4]调整
- AI 不直接启动 Agent 搜索
- 用户确认后才执行 Phase 3

---

## UC4.4 自定义维度（行为）

### 验收标准

用户可以完全自定义调研维度，不走预设推荐。

### 验证步骤（手动）

1. 执行 `/harness-research`
2. 明确说自己要定义维度

### 验证 prompt

```
/harness-research

我想调研宠物食品市场，但我自己定义维度：
1. 头部品牌分析
2. 价格区间分布
3. 用户购买渠道
```

### 通过条件

- AI 接受用户定义的维度
- 不强推预设维度
- 按用户维度执行搜索

## 4. 关键算法

### 4.1 代码块移除

```python
# mdcounter.py:40-41
content_no_code = re.sub(r'```.*?```', '', content, flags=re.DOTALL)
content_no_code = re.sub(r'`[^`]+`', '', content_no_code)
```

**为什么两个 re.sub**：
- 第一个处理多行代码块（``` ... ```）
- 第二个处理行内代码（`...`）

### 4.2 中文范围判断

```python
# mdcounter.py:63
return sum(1 for char in text if '一' <= char <= '鿿')
```

**Unicode 范围**：
- `'一'` = U+4E00
- `'鿿'` = U+9FFF
- 覆盖 CJK Unified Ideographs（常用汉字 20,902 个）

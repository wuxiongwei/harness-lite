### M3 · 过度设计的识别原则

block-push.sh 教训：每加一层防护时问 3 个问题：
1. 已有几层？（principles.md / permissions.deny / hook）
2. 这一层覆盖什么前 N 层覆盖不到的场景？
3. 这一层会误拦什么合理场景？

→ block-push 在第 1 + 2 + 3 都失败。删除是对的。

加入 backlog："Defense layer addition checklist"。

### M4 · "凭印象写"的根本解药

5 次同根 bug 都指向同一动作：**对外接受 schema 时直接 Read 官方 docs**。已多次验证：5 分钟读 docs 抵几小时事后修。

→ 加入 backlog："任何对接 Claude Code 元数据 / Hook / Skill / Agent 字段时，必须先 fetch 当前最新 docs 再写。"

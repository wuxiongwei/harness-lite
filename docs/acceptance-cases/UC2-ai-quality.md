# UC2 AI质量类验收用例

> 验证目标：AI产出质量稳定（不再"自由发挥"）

---

## UC2.1 技术栈规则生效（行为）

### 验收标准

AI 编码时不使用被禁止的语法，遵守 tech-stack-rules.md 约束。

### 验证步骤（手动）

1. 在项目 tech-stack-rules.md 中设置禁止项（如"禁止使用 Java record"）
2. 让 AI 写一个数据类
3. 观察 AI 是否避免使用禁止语法

### 验证 prompt

```
帮我写一个 User 数据类，包含 name 和 age 字段
```

### 通过条件

- AI 使用传统 class + getter/setter（而非 record）
- AI 在代码前可能说明"按技术栈规则，使用传统 class"

---

## UC2.2 外科手术式改动（行为）

### 验收标准

AI 不主动加未要求的功能、不顺手优化邻近代码。

### 验收步骤（手动）

1. 给 AI 一个小修改任务
2. 观察改动范围是否精确

### 验证 prompt

```
把 src/main.py 第 10 行的 print("hello") 改成 print("Hello, World!")
只改这一行，不要改其他内容
```

### 通过条件

- 只改指定的那一行
- 不顺手改格式/注释/邻近代码
- 不加新功能

---

## UC2.3 不假设用户意图（行为）

### 验收标准

遇到歧义时，AI 列出选项让用户选择，不静默选一个。

### 验证步骤（手动）

给 AI 一个有歧义的任务，观察是否询问。

### 验证 prompt

```
帮我加一个登录功能
```

### 通过条件

- AI 询问：用什么方式登录？（手机号/邮箱/第三方）
- AI 询问：需要记住登录状态吗？
- AI 不静默假设"肯定用手机号登录"

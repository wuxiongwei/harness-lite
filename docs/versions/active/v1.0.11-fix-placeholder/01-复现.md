## 1. 触发动机

v1.0.5-v1.0.10 修过 5 类 schema 漂移、3 类残留 bug。共性都是"凭印象写、实战才发现"。复盘时主动审计 `templates/` 与 `init.sh` / `upgrade.sh` 渲染规则的差集：

```bash
diff <(grep -oE "\{\{[A-Z_]+\}\}" templates/CLAUDE.md | sort -u) \
     <(grep -oE "\{\{[A-Z_]+\}\}" scripts/init.sh    | sort -u)
> {{HARNESS_LITE_DOCS_URL}}
```

→ **找到 1 个**：`templates/CLAUDE.md` 第 305 行用了 `{{HARNESS_LITE_DOCS_URL}}`，但 init.sh 渲染列表里**没这个变量**——所有装过 Harness-Lite 的项目 CLAUDE.md 都会残留这个字面量。

---

## 2. 实测复现

```bash
$ grep "{{" /Users/zoe/Documents/codes/gitee-hub/stock_make_money/CLAUDE.md
{{HARNESS_LITE_DOCS_URL}}
```

✅ stock 端 100% 残留（自 v1.0.4 安装以来一直存在 → 升级到 v1.0.9 时还在 → 直到 v1.0.10 commit 才被发现）。

→ **额外发现 1**：手动跑 validate.sh 检查 stock 还揪出 `.claude/rules/domain-rules.md` 也残留 `{{HARNESS_LITE_VERSION}}` / `{{INSTALL_DATE}}`。但 init.sh 实际上**有**渲染 domain-rules.md——为何还残留？

→ **额外发现 2**：原因是 v1.0.9 的 `upgrade.sh` 用 templates 覆盖了 domain-rules.md，**但没渲染**。这是 upgrade.sh 的姊妹 bug——也是同根（"占位符未渲染"）。

## 2. 改动方案（一段话讲清楚）

```
做什么：
  - 解锁 Lite 档（让用户能选 1-3人 配置）
  - 给 PROJECT_NAME 加默认值（取当前目录 basename）
  - 顺手：TEAM_SIZE 根据 TIER 自动给默认值

为什么：
  - Lite 锁住违反"产品宪法"——v1.0 已经支持单人使用，没理由禁选
  - 空的项目名让用户在 stock_make_money 这种场景重复打字（违反 init.sh"开箱即用"承诺）

怎么做：
  - interactive_tier()：option 1 改为 TIER="lite"（不再强转 standard），文案去掉"v1.3 不可用"
  - interactive_project_info()：
      PROJECT_NAME=${PROJECT_NAME:-$(basename "$TARGET_DIR")}
      TIER 决定 TEAM_SIZE 默认值（lite→"1-3人" / standard→"4-10人"）
```

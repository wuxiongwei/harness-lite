## 已知遗留

1. **退出码细节**：反向测试时 validate.sh 末尾输出 "✗ 发现 1 个问题"，但 `echo $?` 显示 0——这是因为脚本里 `errors=$((errors+1))` 只加了一次（当 schema_ok=false 时只 +1，不管几条不变式失败）。**已知不修**：用户能从屏幕看到具体哪 5 条失败，1 vs 5 的数字不影响判断。下次有人反馈再修。

2. **jq 不可用时的降级覆盖度**：仅做 JSON 语法校验，schema 检查会被跳过。**接受**：jq 是常用工具，提示装即可，不引入额外依赖。

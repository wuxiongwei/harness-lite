## 1. 架构设计

### 1.1 模块划分

```
mdcounter/
├── mdcounter.py          # 主入口 + CLI
├── parser.py             # Markdown 解析
├── counter.py            # 统计逻辑
└── tests/
    ├── test_parser.py
    ├── test_counter.py
    └── fixtures/
        └── sample.md
```

### 1.2 数据流

```
用户输入（file/stdin）
    ↓
[parser.py] 解析 markdown → 纯文本 + 元数据
    ↓
[counter.py] 统计 → {中文字数, 英文词数, 行数, 链接数}
    ↓
[mdcounter.py] 格式化输出 → stdout
```

### 1.3 关键决策

| # | 决策项 | 选项A | 选项B | 选择 | 理由 |
|---|-------|-------|-------|------|------|
| D1 | Markdown 解析方式 | 正则 | `mistune` 库 | **B** | 正则易出错；`mistune` 成熟稳定 |
| D2 | 中文统计方式 | 字符数 | 分词后词数 | **A** | v0.1 简化；分词库重 |
| D3 | CLI 框架 | `argparse` | `click` | **A** | 标准库无额外依赖 |
| D4 | 打包方式 | 单文件 | pip 包 | **A** | 示例项目保持简单 |

## 3. 核心算法

### 3.1 中文字数统计

```python
def count_chinese(text: str) -> int:
    """统计中文字符数（不含标点）"""
    return sum(1 for char in text if '一' <= char <= '鿿')
```

**边界处理**：
- 只统计 CJK Unified Ideographs 区间（U+4E00 - U+9FFF）
- 排除中文标点（，。！？等）

### 3.2 英文单词统计

```python
def count_english_words(text: str) -> int:
    """统计英文单词数"""
    # 移除中文字符
    text_no_chinese = re.sub(r'[一-鿿]', '', text)
    # 按空白分割
    words = text_no_chinese.split()
    # 过滤纯标点
    return len([w for w in words if re.search(r'[a-zA-Z]', w)])
```

### 3.3 链接提取

```python
def extract_links(content: str) -> List[str]:
    """提取 markdown 链接"""
    # 正则：[text](url)
    pattern = r'\[([^\]]+)\]\(([^)]+)\)'
    return re.findall(pattern, content)
```

## 6. 性能考量

| 目标 | 实现 |
|-----|------|
| 100KB < 100ms | `mistune` 解析 + 单次遍历统计 |
| 内存占用 < 10MB | 流式读取（暂不实现，v0.1 全加载） |

**性能瓶颈识别**：
- markdown 解析：`mistune` 已优化，无需自己处理
- 中文统计：单次遍历 O(n)，可接受

## 元发现

### M1 · 静默失败的可怕

upgrade.sh 失败时：
- ❌ 不打红框
- ❌ 不 exit 非 0
- ❌ 备份目录正常生成
- ❌ 只在 stderr 闪过一行 bash 错误

→ 用户被骗 3 周（v1.0.11 引入到 v1.0.18 修复）。

**沉淀**：所有脚本必须**显式失败**：
- exit 1 + 红色提示
- 不依赖用户去看 stderr

### M2 · validate.sh 防护网兑现

```
v1.0.11 加 "占位符自检"（第 4 维）
   ↓ 等待 21 天
v1.0.18 这层网今天抓到 P0 bug
```

→ **预防层投资即使 ROI 不立即显现，长期一定回本**。

### M3 · 同根第 6 次的横向网

| 同根表象 | 沉淀位置 |
|--------|---------|
| v1.0.5/7/11/12 schema 漂移 | validate.sh 6 维自检 |
| v1.0.13 backlog 欠款 | proposals.md 持续追溯 |

v1.0.11 复盘说"已修 upgrade.sh 渲染逻辑"——**实际从未在真实 upgrade 路径跑过**。
v1.0.13 我自己沉淀过"backlog 欠款"——**类似的风险在脚本层也存在**。

→ 加入 backlog："修任何 bug 必须在 bug 真实出现路径上验证"——具化 v1.0.13 协议升级。

### Stock_make_money 现象："运行运行就停了，经常出现"
- 发现日期：2026-06-16
- 来源：用户在 stock_make_money 实战 H-L v1.0.4-v1.0.12 期间观察
- 现象：
  - claude REPL 跑着跑着停止响应（**不是真正卡死**——用户敲"继续"或"你卡住了"AI 能接着写）
  - 频次：经常出现
  - 卡住时屏幕最后一个符号是 **冒号"："**
- **诊断（已确认）**：是 Claude Code 响应流偶发截断，**不是 H-L 范围**
  - 冒号位置说明 AI 正在生成文字（"以下：" / "原因：" / "步骤："），流被打断
  - 用户敲"继续"AI 能恢复 → 排除 hook 卡住、subagent 死锁、网络断、token 耗尽
  - 真因：API 响应流偶发截断，客户端没把"流结束"明显提示给用户
- **应对手段**（已告诉用户）：直接敲 `继续` 即可
- 处理状态：📌 **不在 H-L 责任面**——记录仅为帮用户分辨"H-L 问题 vs Claude Code 偶发"
- 关联：v1.0.12 修了 hook if 字段格式（之前 stock 装的 v1.0.4-v1.0.11 含错格式 if，但这与"冒号截断"症状无关）

## 3. 根因分析（关键！必须深挖）

### 3.1 直接原因（What）

```
直接原因：（代码层面发生了什么）

例如：
- 并发情况下两个线程同时读取余额，都通过了校验
- 字符串截取使用 substring 但忘记了 mask 字符
- ...
```

### 3.2 根本原因（Why）

```
根本原因：（为什么会发生）

例如：
- 缺少分布式锁
- 业务层手写脱敏逻辑而未使用 @Desensitize 注解
- ...
```

### 3.3 设计/流程缺陷（Why-Why）

```
深层原因：（为什么"为什么会发生"会发生）

例如：
- 当时设计没考虑高并发场景
- 团队没有"注解优先于手写"的规范
- ...
```

⚠️ 必须挖到第三层（Why-Why）才算根因明确，否则只是补丁式修复。

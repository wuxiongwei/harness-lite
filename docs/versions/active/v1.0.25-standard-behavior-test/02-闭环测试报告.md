## 🔴 真闭环测试**真发现的 2 个 bug**（已修）

### Bug 1 · assignments schema 不感知

**现象**：用 `cat >> .claude/assignments/zoe.md` 追加新 claim，结果错误插入到"已完成（done）"段（文件末尾），不是"进行中（claimed）"段。

**根因**：v1.0.23 §14 + assignments/README.md schema 规定了三段结构（进行中 / 待办 / 已完成），但**没明确指示 AI 如何插入**。

**修复（已落地）**：`templates/.claude/assignments/README.md` 加"必读 bug 警告"段：
- 必须 Read 全文 → 找 `## 进行中（claimed）` → 在该段插入 → Write 全文
- 禁止 cat >> 追加 / 禁止简单字符串匹配末尾段落

### Bug 2 · A3 判断未排除"自己的 claim"

**现象**：A3 检查文件冲突时，把"我自己 claim 的文件"也算成冲突——但自己 claim 自己改不是冲突。

**根因**：v1.0.23 §14 + harness-impact SKILL.md 没明确"排除自己"。

**修复（已落地）**：`templates/.claude/skills/harness-impact/SKILL.md` 加判定逻辑：
```
overlap = 改动文件 ∩ (所有人 claim - 当前用户 claim)
```

## 关键发现

### ✅ 正面发现 1 · B1 协同视角段**真自动触发**

写 `01-需求.md` 时，**没有任何外部提示**让我加协同视角段，但因为：
- principles §14.5 规定"协同视角段在主产物末尾"
- harness-req SKILL.md Phase 5.7 写明触发位置

我**在写产物时主动按协议加了**——RD 视角 3 条 + QA 视角 4 条。

**这是 v1.0.24 §13.1.1 / §13.1.2 强约束起作用的实证**——协议落地后**自然触发**了 B1。

### ✅ 正面发现 2 · A3 协作冲突预警**也自动触发**

写 01-需求.md 时主动加了"## 🤝 协作冲突预警"段——同样无外部提示。

### 🟡 中性发现 · A1 / A2 在被指示测试后才触发

A1 / A2 是 git commit / 创建版本目录前的"前置检查"，本次测试**没有真走 git commit / 创建版本目录的命令**——所以 A1/A2 是被我主动指示去验证才触发，不是自然触发。

→ 这两个能力的"自然触发率"待 stock 真实使用时验证。

### ✅ 正面发现 3 · 决策学习协议**继续真触发**

测试期间产生的决策点（v0.4 命名 / RD 视角条数 / 测试方法选择）应该 append decision-log。本次测试相对偏"指令执行"少决策，但仍按 §13.1.2 自检清单走。

### 🔴 负面发现（诚实）

测试本身的**根本方法论 gap**：我自己测自己 + 已知协议 → 无法证明在 fresh AI session 下协议会自然触发。**真正的测试要等 stock 团队真实使用**。

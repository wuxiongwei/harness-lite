## 1. 触发动机

v1.0.5-1.0.7 三连击修完了 schema 漂移这条主线。复盘时意识到：**uninstall.sh 自 v1.0.2 后从来没回归过**。这期间产品加了不少东西。

→ 主动审计 uninstall.sh 与当前模板清单是否同步。

---

## 2. 实测复现

```bash
# 在 /tmp 装一份
mkdir /tmp/hl-cycle && cd /tmp/hl-cycle && git init
~/Documents/codes/gitee-hub/harness-lite/scripts/init.sh

# 装完后 .claude/ 共 26 个 Harness-Lite 文件
find .claude -type f | wc -l    # 26

# 跑卸载
echo YES | ~/Documents/codes/gitee-hub/harness-lite/scripts/uninstall.sh

# ❌ 残留：
find .claude -type f
.claude/skills/harness-impact/SKILL.md      # 残留
.claude/skills/harness-test-ci/SKILL.md     # 残留
.claude/hooks/pre-commit-test.sh            # 残留
.claude/hooks/block-push.sh                 # 残留
.claude/hooks/distill-prompt.sh             # 残留
```

---

## 3. 残留清单与引入版本对照

| 残留文件 | 引入版本 | uninstall.sh 漏的原因 |
|---------|---------|---------------------|
| `skills/harness-impact/` | v1.0.2 | 加 skill 时没改 uninstall |
| `skills/harness-test-ci/` | v1.0.2 | 同上 |
| `hooks/pre-commit-test.sh` | v1.0.2 | hooks/ 整个目录没出现在 uninstall 清单 |
| `hooks/block-push.sh` | v1.0.5 | 同上 |
| `hooks/distill-prompt.sh` | v1.0.5 | 同上 |

**5 个残留**，全部由"加新东西时不更新清单"造成。

---

## 4. 影响面

- ❌ 卸载后 `.claude/skills/` / `.claude/hooks/` 目录不为空，rmdir 失败 → `.claude/` 父目录也清不掉
- ❌ 用户重装时这 5 个旧文件可能版本不同步（如 hooks 脚本）
- ✅ 不影响 init / 日常 skill 调用 / 全量测试

→ P2 级别（让人有"卸载没干净"的不适，但不影响使用）。

**路径 C**——是 bug：自 v1.0.2 起一直有，v1.0.5 + v1.0.7 又叠加了 3 个新残留。100% 可复现。

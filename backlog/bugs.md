### Stock_make_money 现象："运行运行就停了，经常出现"
- 发现日期：2026-06-16
- 来源：用户在 stock_make_money 实战 H-L v1.0.4-v1.0.12 期间观察
- 现象：
  - claude REPL 跑着跑着停止响应（**不是真正卡死**——用户敲"继续"或"你卡住了"AI 能接着写）
  - 频次：经常出现
  - 卡住时屏幕最后一个符号是 **冒号"："**
- **2026-06-16 活体复现**：AI（Claude）在与用户对话中**自身也复现**了该现象——说完"再补一次："后没有触发预期的工具调用直接停止。用户当场指出后才被识别。
- **诊断（修正版，已确认）**：**模型在"引出动作"的句子后过早判断 end_turn**，而非 Claude Code 流截断
  - 模型生成"我要做 X：" / "再补一次：" / "继续：" 等引出语后，错误地认为这一回合输出已完成 → 返回 stop_reason="end_turn"
  - 用户敲"继续"AI 恢复 = 新一轮上下文中模型看到"我说了要做但没做"，自动补上动作
  - 排除：① hook 卡住 ② subagent 死锁 ③ 网络断 ④ token 耗尽 ⑤ Claude Code 流截断
- **应对手段**：直接敲 `继续` / `你卡住了` 即可
- **预防手段**（写在 H-L principles）：
  - AI 自己写"我要做 X："这种引出语前 → 应**先做 X 再写解释**，避免引出后停止的风险
  - 或写完引出语后立刻 tool call，不在 message 里中断
- 处理状态：📌 **不在 H-L 直接责任面**，但已加入 backlog 待 v1.1+ 在 principles.md 增加"AI 输出节奏守则"（避免引出后 end_turn）
- 关联：v1.0.12 修了 hook if 字段格式（无关）

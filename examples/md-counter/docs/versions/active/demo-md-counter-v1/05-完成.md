| 阶段 | 产物行数 | 耗时（估算） | 卡点 |
|-----|---------|------------|------|
| 1. 需求 | 202 行 | ~30min | 无 |
| 2. 设计 | 286 行 | ~40min | 无 |
| 3. 代码+索引 | 145+220 行 | ~1h | 无 |

| 5. 完成 | 本文档 | ~15min | 无 |

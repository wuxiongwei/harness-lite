## 3. 影响面

- **门禁失效**：因 "Files with errors are skipped entirely"，整个 settings.json 失效
  - `permissions.deny`（敏感文件保护）失效
  - `pre-commit-test.sh` 全量回归 hook 不会触发
  - `block-push.sh`（其实当时还没独立成脚本）不生效
- **用户体验**：每次启动 `claude` 都要看到红色报错
- **隐性风险**：用户选 "3. Continue without these settings" → 等于裸跑，所有 Harness-Lite 门禁失效

---

## 4. 关键证据

报错日志已显示：
- `matcher: Expected string, but received object` → 我用了 `{"tool":"Bash","matchGlob":"git commit*"}` 对象形式
- `hooks: Expected array, but received undefined` → 我直接在 hook entry 平铺 `command`，没有 `hooks: []` 一层

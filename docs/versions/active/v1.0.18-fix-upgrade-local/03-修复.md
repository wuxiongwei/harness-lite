## 为什么 stock 会失败 4 次升级仍没察觉？

1. **6/16 v1.0.9 实战测试** — 那时 upgrade.sh 没有 v1.0.11 的 `local`，**这次成功**了
2. **6/16 v1.0.11 修占位符** — 我手动 sed 修了 domain-rules，没跑 upgrade
3. **6/17 11:03 用户跑 upgrade** — `local` 报错，**第一次失败**但用户没察觉
4. **6/17 11:13 user 跑 validate** — 第 4 维占位符自检抓到

**用户跑 validate 是关键信号**——没有 v1.0.11 加的这层网，bug 还在潜伏。

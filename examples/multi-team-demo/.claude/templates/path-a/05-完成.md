## 决策回顾（v1.0.21+ · principles §13）

> 本段自动触发：读取本次迭代的决策日志，批量授权哪些以后别问。

### 执行流程

1. **读取本次迭代决策**：
   ```bash
   Read .claude/decision-log.md
   过滤本次版本 ID 的条目（状态 = ⏳ 待复盘）
   ```

2. **如有 N > 0 条 → 触发批量授权对话**：
   ```
   🔍 本次迭代被询问的决策（N 条）：
   
   [1] {决策标题 1}（你选了 {选择}）
   [2] {决策标题 2}（你选了 {选择}）
   ...
   
   对每条选择处理：
   - [a] 以后别问（写入 auto-decide）
   - [s] 继续问（保留询问）
   - [d] 删除记录（不学习）
   
   请输入：1=a,2=s,3=a 或 all=a 或 quit
   ```

3. **用户选择处理**：
   - 选 `a` → 写 `.claude/auto-decide.md` 一条 + 改 decision-log 状态为 ✅
   - 选 `s` → 改状态为 🔁 保留询问（下次仍问）
   - 选 `d` → 改状态为 🗑 已删除
   - `quit` → 全部不动（下次仍触发）

4. **清理 decision-log**：
   复盘后，将本次状态非 ⏳ 的条目从 decision-log.md 移除（保留追溯靠 auto-decide.md 的"来源"字段）。

### 示例输出

```
✓ 已写入 .claude/auto-decide.md：
  - 表格格式 → Markdown 表
  - commit message 格式 → feat: [模块] - ...

✓ 保持询问：
  - 模块拆分粒度（项目特性强相关，每次都问）

📝 撤回任何授权：编辑 .claude/auto-decide.md
```

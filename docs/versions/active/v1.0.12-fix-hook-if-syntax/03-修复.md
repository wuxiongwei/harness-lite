### validate.sh 第 6 条不变式

```bash
bad_if=$(jq -r '
    [.hooks.PreToolUse, .hooks.PostToolUse] | flatten | map(.hooks[]?.if // empty)
    | map(select(test("\\([^)]*[a-zA-Z]\\*\\)")))   # 检测 (xxx*) 末尾紧贴 *
    | .[]
' ".claude/settings.json" 2>/dev/null)
if [ -n "$bad_if" ]; then
    echo "✗ hook 'if' 字段格式错误（命令与 * 之间缺空格）："
    echo "$bad_if" | sed 's/^/      /'
    echo "    修法：'Bash(git commit*)' → 'Bash(git commit *)'"
fi
```

## block-push 删除影响评估

| 防护场景 | 之前（3 层）| 现在（2 层）|
|---------|-----------|-----------|
| AI 主动 push 普通分支 | hook 拦 + principles 规劝 | principles 规劝 ✅ 仍生效 |
| AI 主动 push --force | hook 拦 + permissions.deny + principles | permissions.deny ✅ + principles ✅ |
| 用户授意 AI 帮 push | hook **误**拦 → 用户被迫自己跑 | 顺利执行 ✅（修了扰民） |
| 用户在终端自己 push | 三层都不触发 | 不变 ✅ |

→ **删除让"用户授意 AI"场景不再被误拦，其他场景防护强度不变。**

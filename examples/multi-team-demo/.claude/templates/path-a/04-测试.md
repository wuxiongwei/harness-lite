#### E2E 4步法（强制）

```
Step 1: 环境 Readiness
  - [ ] Schema Diff
  - [ ] DB/Redis/API ping
  - [ ] 配置校验
  - [ ] 端口/服务状态

Step 2: 启动服务
  - [ ] 已运行则复用
  - [ ] 未运行则启动并等待健康检查

Step 3: 真实请求验证
  - [ ] 正向主链路
  - [ ] 跨工程接口一致
  - [ ] 404/400/401/注入/空数据等边界

Step 4: 数据落库校验
  - [ ] 直连DB SELECT 验证字段
  - [ ] 字段值与接口返回一致
  - [ ] 旧数据兼容
```

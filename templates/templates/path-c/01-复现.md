
## 5. 失败回归测试（关键！）

> 路径C硬规则：能写失败测试时，必须先写 RED

### 5.1 是否能写失败测试？

- [ ] 能 → 写在下面（必须先 RED）
- [ ] 不能 → 说明原因（如外部依赖、UI层）

### 5.2 RED 测试

```code
// 路径: src/test/.../BugRegressionTest.{java,ts}
@Test
void should_xxx_when_yyy() {
    // Given - 复现条件
    
    // When - 触发操作
    
    // Then - 当前会失败的断言
}
```

### 5.3 RED 验证

```
执行命令：{{TEST_COMMAND}}
执行结果：❌ Failed (符合预期)
失败原因：（错误信息，证明这就是bug）
```

⚠️ 测试必须先失败！如果"测试意外通过"，说明用例没复现 bug，需要重写。
